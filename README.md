These are fixes for the 9-pin version of the RetroBit controller ([Genesis](https://retro-bit.com/controllers/genesis/#console) or [Mega Drive](https://retro-bit.com/controllers/mega-drive/#console)

* Fixed:
- Lost Vikings: Fixes an issue where the game doesn't register the signal sent from the C-button as a button press
- Phantom 2040: Fixes the controller layout entirely. Manual says: A: Punch, B: Energy Blast, C: Jump, Z: Induction Rope. On my controller it was: A: Energy Blast, B: Induction Rope, if pressed with a direction, C: Toggled run if you already were walking, Z: Induction Rope. Use MODE instead of Start, as the RetroBit start key will not work.
